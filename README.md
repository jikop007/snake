Как начать есть яблоки:
Linux? - читай дальше
Windows? - установи wsl, в терминале напиши wsl

Инструкция:
1. make - Собрать игру
2. ./snake - запустить игру
3. Кнопка w - направить змейку вверх, s - вниз, a - влево, d - направо, esc - преждевременное завершение игры
4. make clean - удаляет сборку игры

Приятного аппетита :)
